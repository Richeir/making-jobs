# 上下文工程

> 这是第一张「单项技能深入页」示例：frontmatter 的 `checklist: ["3.1"]`
> 会让清单页 3.1 块自动长出「📖 深入 →」链接。改这两个字的 id 就能挂到别的块。

## 为什么它进面试

2027 的笔试双轨里，允许用 AI 的那条线考的不是"会不会用工具"，而是
**把 AI 当工程系统用**：上下文怎么给、结果怎么验、失败怎么归因。

## 核心动作

- 先给边界与验收标准，再给材料：`约束 → 目标 → 素材 → 输出格式`
- 分窗口管理长任务：探索 / 实现 / 评审各用干净上下文
- 对 AI 产出做**廉价验证**：断言、diff、小样本回放，而不是"看起来对"

```py
# 例：给 AI 的验证脚本骨架（面试手撕友好）
def check(out): assert out["status"] == "ok", out
```

## 证据怎么准备

挑一个真实项目，写清：喂给 AI 的上下文结构、一次失败归因、修复后的验收方式。

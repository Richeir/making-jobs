# 📖 单项技能深入页是干什么的

清单里的每一条都是**一句话的行为要求**——它必须短，才能在 178 条里保持可读。
但有些能力一句话说不清：MVCC 到底怎么算可见性、一次 eval 集怎么搭、简历上那行字为什么会让你多聊十分钟。

深入页就是为这些能力准备的：**一个能力块对应一张页**，写清单塞不下的那部分。

## 它和清单怎么连起来

每张深入页的 frontmatter 声明自己覆盖哪些块：

```yaml
---
title: 上下文工程
checklist: ["3.1"]   # 清单块 id
---
```

构建期 `tools/build-checklist.mjs` 扫 `docs/skills/*.md`，于是：

- 清单页对应块上长出「**📖 深入 →**」链接，直接跳到这里；
- 本页自动进左侧「📖 深入 · 层名」侧边栏，按层归组；
- 一个块只挂一张页（多张时按文件名顺序取第一张），所以**别为同一个 id 写两页**——要覆盖多个块就在 `checklist` 里并列写全，如 `["3.1", "3.2"]`。

块 id 从清单页地址栏就能读到（`#card-3` 是卡，块 id 印在每个块的 `data-blk` 上，如 `2.1`、`2.1#3`）。

## 一页该写什么

拿 `_template.md` 起步，四段是够用的骨架：

| 段 | 要回答的问题 |
| --- | --- |
| 为什么它进面试 | 招聘方用它筛什么；丢掉它的代价是什么 |
| 核心动作 | 具体怎么做，可执行、可复述，不要"深入了解"这种话 |
| 常见失败 | 你或候选人真实踩过的坑，最好带一段反例代码或一段对话 |
| 证据怎么准备 | 面试时你能指着什么东西说话——截图、录像、错题本、评测集 |

判断标准很硬：**写完回看清单对应块，每一条你都能指着本页说出证据在哪。**
说不出，这页就还没写完。

## 还没有的页

清单里有 40 多个块，深入页只有个位数。挑你现在正在补的那一块，
复制 `_template.md` 开写——这也是这份清单少有的、**现在就能动手**的贡献方式。
